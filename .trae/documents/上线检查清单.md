# TalkPilot 上线检查清单

## P0：提审前必须完成

- [ ] `npx tsc --noEmit` 通过，且没有新的 TS / 路由类型错误
- [ ] 正式包移除开发态 ATS 配置：`NSAllowsArbitraryLoads`、局域网 IP 白名单、仅开发用的 `NSLocalNetworkUsageDescription`
- [ ] 生产环境 `EXPO_PUBLIC_SUPABASE_URL` / `EXPO_PUBLIC_SUPABASE_ANON_KEY` / RevenueCat / Google Sign-In 全部配置完整
- [ ] 真机走通匿名启动、正式登录、退出后回落匿名态
- [ ] 真机走通订阅购买、恢复购买、Customer Center 返回后的状态刷新
- [ ] 真机走通 Live 会话主链路：开麦、转写、suggest、review、挂断、历史入库
- [ ] 历史会话页与详情页可正常读取，历史语言快照显示符合预期
- [ ] Paywall、Terms、Privacy、Restore Purchases、订阅披露文案与商店后台一致
- [ ] App Review Notes、隐私政策 URL、服务条款 URL 已填入商店后台

## P1：强烈建议在首发前完成

- [ ] 正式包不可访问 `/(dev)` 路由，设置页 debug 入口只在 `__DEV__` 出现
- [ ] Sentry release 环境可收到错误，并已验证 source map / dSYM 上传链路
- [ ] PostHog 开发环境默认不上报，生产环境事件字段符合隐私约束
- [ ] Supabase Edge Functions、RevenueCat webhook、subscription sync 都已指向生产环境
- [ ] 核对 App Store 截图、描述、关键词、年龄分级、审核备注
- [ ] 审核备注中说明实时语音/后台音频用途，以及测试订阅的入口路径

## P2：首发后可继续迭代

- [ ] 清理 `app.json` 中仅为开发调试保留的网络例外配置生成逻辑
- [ ] 为发布前检查补一个脚本或 CI job，固定校验 TS、法务链接、关键 env
- [ ] 继续完善会员漏斗、会话质量、错误聚合等运营指标
- [ ] 二期能力按计划恢复：Coach、场景推荐、云端 TTS
